# v9 changes
- My Models menu: whole palette now scrolls (controls + full list).
- Gravestone: new "Gravestone" item (Stations tab). Shows in 3D and 2D, move/rotate/delete, swap look with any .glb ("Machine look" / "Use my model"), or turn a placed model into it with "Make it a...". Works in the game and on the minimap. Maps with no gravestone placed show none.
- Escape Door: can wear any .glb (same bar as machines). "Make it a... > Escape Door" also works.
- HUD: Layout editor now has Move / Style. Themes (Original, Neon Cyan, Neon Pink, Neon Rainbow, Military, Gold, Clear Glass), per-button picture from your files, neon colour/glow/pulse, fonts, text colour, shape, hide icon+text. Opened from Settings > "Button Looks".
- Map Settings is a bottom sheet with a real background + "See-through" toggle. HUD editor shows the game behind it (Dim slider) and hides the settings page.
- Removed the R9S Juggernog (catalog entry + perk_juggernog.glb).
